- VI-36 D4′ 이웃 사용 열쇠는 base_pairs 에만 적용한다(42w 와 같은 꼴).

- 반복 시험에서 찾아 고친 결함:
  - VI-43 obs_build 는 k 도 같아야 한다.
  - VI-44 unit_valid 는 「삽입 중」을 유효로 보지 않는다.

## 정의에 되돌릴 것 (state_corrections)
- D10 F_f → 바이트 연속(VI-35).
- D11 의 「𝔅 를 움직인 턴이 단위를 본다」만으로는 모자란다. 설치 뒤 확인이 엄격해야 한다(VI-44).
- P-9 창은 집합뿐 아니라 위치도 같아야 한 상태다(VI-43).
- P-10 3단계 「관찰자 즉시 다시 짓기」 → 쓸 때 확인(VI-40).
- T5-2 의 관찰자 상한은 늦은 턴 하나 기준으로 읽었다. 파일 전체 합(두 늦은 턴, 3,278·3,093)은 2×1080 을 넘는다. 둘이 겹쳐 일할 때의 중간 상태 때문이다. **기준 문구가 모호했다** — 다음 판에서 실행 전에 분명히 한다.
- 문서의 「동기 세기」(vrs_insert 가 돌아올 때 pend == 0)는 더는 성립하지 않는다. 세기는 일 단위로 한다.
